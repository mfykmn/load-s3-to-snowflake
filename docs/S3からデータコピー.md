# S3からデータコピー

## 事前準備

[認証設定](./S3認証設定.md) を実施

## External Stage作成

```sql
USE KAFKA_DB.KAFKA_SCHEMA;
CREATE STAGE IF NOT EXISTS COMMON_STAGE
  URL='s3://test-camel-debezium-to-s3/'
  STORAGE_INTEGRATION=s3_int
  FILE_FORMAT=(TYPE=JSON COMPRESSION=AUTO);
```

## Raw Table

```sql
USE KAFKA_DB.KAFKA_SCHEMA;
CREATE TABLE IF NOT EXISTS RAW_TABLE (
  payload VARIANT,
  source_file STRING,
  source_row_number NUMBER,
  loaded_at TIMESTAMP_NTZ
);
```

## Copy into

```sql
USE KAFKA_DB.KAFKA_SCHEMA;
COPY INTO RAW_TABLE (payload, source_file, source_row_number, loaded_at)
FROM (
  SELECT
    $1,
    METADATA$FILENAME,
    METADATA$FILE_ROW_NUMBER,
    CURRENT_TIMESTAMP()
  FROM @COMMON_STAGE/sqlserver-cdc-DDL/
)
PATTERN='.*\\.jsonl\\.gz'
ON_ERROR='CONTINUE';
```
