# S3認証設定

## Storage Integration

### 1. Snowflake 側で Storage Integration を作成

```sql
CREATE STORAGE INTEGRATION IF NOT EXISTS s3_int
  TYPE = EXTERNAL_STAGE
  STORAGE_PROVIDER = 'S3'
  ENABLED = TRUE
  STORAGE_AWS_ROLE_ARN = 'arn:aws:iam::0:role/role_name'
  STORAGE_ALLOWED_LOCATIONS = ('s3://test-camel-debezium-to-s3/');
```

※ STORAGE_AWS_ROLE_ARN はダミー値で作成、後々更新する

### 2. Storage Integration からRole作成のための情報を取得

```sql
DESC INTEGRATION s3_int;
```

`STORAGE_AWS_IAM_USER_ARN` と `STORAGE_AWS_EXTERNAL_ID` を控える

### 3. AWS 側でロール作成

Principal に `STORAGE_AWS_IAM_USER_ARN`、Condition の ExternalId に `STORAGE_AWS_EXTERNAL_ID` を設定します。

```bash
aws iam update-assume-role-policy \
  --role-name cdc-copy-role \
  --policy-document file://docs/trust-policy.json

aws iam put-role-policy \
  --role-name cdc-copy-role \
  --policy-name cdc-read-s3 \
  --policy-document file://docs/cdc-read-s3-policy.json
```

### 4. Snowflake 側で Storage Integration のRoleを更新

```sql
ALTER STORAGE INTEGRATION s3_int
  SET STORAGE_AWS_ROLE_ARN = 'arn:aws:iam::<account-id>:role/cdc-copy-role';
```
